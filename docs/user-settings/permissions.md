# 사용자 권한 관리

사용자는 Super Admin(관리자), Team Admin(팀장), Team User(팀원), Client User(광고주) 네 가지 권한으로 구분됩니다.

## 권한별 관리 범위

| 권한 | Super Admin (관리자) | Team Admin (팀장) | Team User (팀원) | Client User (광고주) |
|------|------|------|------|------|
| 본부 관리 | 등록·삭제·수정·보기 (전체) | 보기 (소속 본부) | x | x |
| 팀 관리 | 등록·삭제·수정·보기 (전체) | 보기 (같은 본부) | x | x |
| Team Admin 관리 | 등록·삭제·수정·보기 (전체) | 보기 (같은 본부) | x | x |
| Team User 관리 | 등록·삭제·수정·보기 (전체) | 등록·삭제·수정·보기 (같은 본부) | x | x |
| Client User 관리 | 등록·삭제·수정·보기 (전체) | 등록·삭제·수정·보기 (같은 본부) | 등록·삭제·수정·보기 (자기 관리) | x |

## 권한별 메뉴 접근

| 메뉴 | Super Admin | Team Admin | Team User | Client User (광고주) |
|------|------|------|------|------|
| 사용자 설정 | ADMIN 등록/수정, 팀 등록/수정, 팀 user 등록, 광고주 등록, API 연동, 역할 권한 관리 | 팀 user 등록, 광고주 등록, API 연동 | 광고주 등록, API 연동 | x |
| 부정클릭 모니터링 | 부정클릭 모니터링, IP 차단목록, 설정 | 부정클릭 모니터링, IP 차단목록, 설정 | 부정클릭 모니터링, IP 차단목록, 설정 | 부정클릭 모니터링, IP 차단목록, 설정 |
| 통합 광고 리포트 시스템 | 리포트 설정 | 리포트 설정 | 리포트 설정 | x |
| 경쟁사 모니터링 | 모니터링 설정, 검색광고 모니터링, 브랜드 모니터링 | 모니터링 설정, 검색광고 모니터링, 브랜드 모니터링 | 모니터링 설정, 검색광고 모니터링, 브랜드 모니터링 | x |
