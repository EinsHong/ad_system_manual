# 통합 시스템 메뉴얼

관리자 시스템의 주요 기능별 사용 방법을 안내합니다. 왼쪽 메뉴에서 원하는 기능을 선택하세요.

!!! note "문서 상태"
    이 문서는 초안(2026-10-01) 기준입니다. 화면과 기능은 변경될 수 있습니다.

## 메뉴 구성

| 메뉴 | 설명 |
|------|------|
| [사용자 설정](user-settings/team-user.md) | 팀 유저·광고주 등록, 권한 관리, 매체 API 연동 |
| [부정클릭 모니터링](fraud-click/setup.md) | 부정클릭 설정, 모니터링, IP 차단 |
| [경쟁사 모니터링](competitor/overview.md) | 경쟁사의 네이버 SA·브랜드 검색광고 소재 수집 |
| [통합 리포트 시스템](report/overview.md) | 매체별 성과 수집 및 리포트 가공 |
| [광고 대량 등록](bulk-register.md) | 광고 그룹·소재·키워드 대량 등록/수정 (네이버만 지원) |
| [광고 운영 시스템](ad-operations/overview.md) | 광고 운영 현황 확인 및 규칙 설정 |

## 처음 사용하신다면

1. 관리자에게 받은 계정으로 로그인합니다. 계정은 [권한](user-settings/permissions.md)에 따라 사용할 수 있는 메뉴가 다릅니다.
2. 광고주별 매체 데이터를 사용하려면 먼저 [API 연동](user-settings/api-integration.md)을 완료합니다.
3. 사용하려는 기능의 메뉴얼을 확인합니다.
